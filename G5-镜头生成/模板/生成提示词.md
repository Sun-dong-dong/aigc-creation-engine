# 生成提示词

每个任务保存独立的最终交付Markdown，并由内部任务`delivery_file`绑定。文件须包含下列四列镜头表、参考说明和恰好一个完整提示词复制区；复制区正文与`prompt_file`一致。旧稿归档；解释、版本差异及检查结果在复制区外维护。正式稿仍可尚缺生成授权或压缩容量实测，未核实实际入口等必要稿件条件时仍为草稿。

- 初稿复检处置及依据：`revised`（有问题或改动，单独完整新版本）/ `accepted_unchanged`（实际独立复检无问题、字节未变，保留已审原文件）；引用`draft_review`及已审SHA256，不用复制相同文件制造新版本。
- 模型、版本、模式、入口：
- 已读取的官方规范与对应模板：
- 实际参考文件及引用对照：

- 稿件状态：草稿 / 正式稿（对应`formal_prompt_ready`）。
- 生成条件：具备 / 尚缺（对应`generation_ready`）；尚缺项及影响：
- 最终交付文件与内部`review.delivery`、校验报告位置：

### 镜头说明

第 X 段｜对应原分镜：镜头 XX—XX｜总时长：X 秒

| 镜头 | 时间（估算） | 景别与运镜 | 画面、表演和台词 |
|---|---|---|---|
| 01 | 0—X 秒 | | |
| 02a | X—X 秒 | | |

每段交付使用上述四列顺序。每行末列独立写清本镜光源、固定色温（K）和人物具体受光，并与对应模型镜头正文一致；不以表前公共说明或仅首行写光线代替其余行。按实际镜数增减行，单镜只保留一行；时间、景别、运镜和动作与本段提示词及有效分镜一致。“景别与运镜”合并写明景别和摄影机运动，并在需要时简明交代机位与拍摄角度；“画面、表演和台词”先按“画面位置 → 朝向 → 姿态 → 与他人、道具的关系”交代人物站位，再按时间顺序写清动作、反应、表演语气、光源与固定色温（K）、各可见人物的受光部位方向及必要的非对白声音，并把对白或旁白放在相应表演处，注明说话人和声音性质；无对白时自然描述画面，跨镜声音承接时注明。时间未实测使用“时间（估算）”，实测后按实际依据标注。镜头列使用单一有效镜号（例如01、02a）或该段顺序号，不在同一格混写两个编号；原分镜与子镜、切镜的对应关系写在表前。

**参考资产：**列出本段选用的人物、场景、道具和声音参考，以及各自职责；未确认或未提供的说明状态。纯文生且确无参考时也须明确写“无参考”及依据。

### 完整提示词

此处放置对应模型模板填写完成后的单独代码块。格式按模型规范，不能将本模板标题、说明或内部校验字段一并复制给视频模型。

**待验证事项：**只写实际存在的未验证事项及影响，例如压缩时长的容量风险；没有则写“无”。

### 检查与关联

- 对应分镜、选用素材、固定描述及内部任务记录位置与版本：
- 实际复检范围与结论、发现的问题及处理；引用同一任务中的逐镜检查、照明、跨镜衔接和独立复检依据，不重复抄录：
- 程序检查、内容复核和用户确认分别是什么状态；未确认、未检查及其他实际缺口：
- 按需引用画面文字转交索引、容量实测或相邻段依据；无相关事项说明依据：

以上引用不能代替实际审读、四列镜头表或参考说明；逐镜覆盖和发现的问题只在内部任务维护一次。

正文有任何改动时单独保存完整新稿并重新检查；实际独立复检无问题且正文逐字节未变时，可按`accepted_unchanged`保留已审原文件，最终完整阅读稿、独立复检与当前输入绑定仍须齐备。仅改分辨率等参数的任务保留已确认正文，更新相关参数与检查绑定。
