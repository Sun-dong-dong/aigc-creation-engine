# 生成提示词

每项任务交付一个 Markdown 文件，内含四列镜头表、参考说明和恰好一个完整提示词复制区。复制区与正文文件一致。技术状态和绑定依据见[校验说明](../校验说明.md)。

## 任务

- 任务ID、镜号、稿件版本：
- 复检结论及内部任务记录入口：
- 模型、版本、模式、入口：
- 已读取的官方规范与对应模板：
- 实际参考文件及引用对照：
- 入口参数及当前校验报告：
- 稿件状态：草稿 / 正式稿（对应`formal_prompt_ready`）。
- 生成条件：具备 / 尚缺（对应`generation_ready`）；尚缺项及影响：
- 最终交付文件与内部`review.delivery`、校验报告位置：

### 镜头说明

第 X 段｜对应原分镜：镜头 XX—XX｜总时长：X 秒

| 镜头 | 时间（估算） | 景别与运镜 | 画面、表演和台词 |
|---|---|---|---|
| 01 | 0—X 秒 | | |
| 02a | X—X 秒 | | |

每段交付使用上述四列顺序。每行末列独立写清本镜光源、固定色温（K）和人物具体受光，并与对应模型镜头正文一致；不以表前公共说明或仅首行写光线代替其余行。按实际镜数增减行，单镜只保留一行；时间、景别、运镜和动作与本段提示词及有效分镜一致。“景别与运镜”合并写明景别和摄影机运动，并在需要时简明交代机位与拍摄角度；“画面、表演和台词”先按“画面位置 → 朝向 → 姿态 → 与他人、道具的关系”交代人物站位，再按时间顺序写清动作、反应、表演语气、光源与固定色温（K）、各可见人物的受光部位方向及必要的非对白声音，并把对白或旁白放在相应表演处，注明说话人和声音性质；无对白时自然描述画面，跨镜声音承接时注明。时间未实测使用“时间（估算）”，实测后按实际依据标注。镜头列使用单一有效镜号（例如01、02a）或该段顺序号，不在同一格混写两个编号；原分镜与子镜、切镜的对应关系写在表前。

逐镜核对分镜中已定的焦段、透视、遮挡与景深设计都已进入模型正文。末列写清相对远近、遮挡及露出时机、焦点、清晰范围、前后景虚化和适用的转焦，并与模型正文语义一致。承接各镜的面部朝向、背景人群处理和表演可读范围。跨机位接同一动作时，说明切出和接入的动作状态。

**参考资产：**列出本段选用的人物、场景、道具和声音参考，以及各自职责。正常场景图负责空间和美术，镜头的虚实、遮挡与焦点变化写进对应镜头。未确认或未提供的说明状态。纯文生且确无参考时也须明确写“无参考”及依据。

### 完整提示词

此处放置对应模型模板填写完成后的单独代码块。格式按模型规范，不能将本模板标题、说明或内部校验字段一并复制给视频模型。

**待验证事项：**只写实际存在的未验证事项及影响，例如压缩时长的容量风险；没有则写“无”。
