# 生成提示词

每个任务保存独立的最终交付Markdown，并由内部任务`delivery_file`绑定。文件须包含下列四列镜头表、参考说明和恰好一个完整提示词复制区；复制区正文与`prompt_file`一致。旧稿归档；解释、版本差异及检查结果在复制区外维护。正式稿仍可尚缺生成授权或压缩容量实测，未核实实际入口等必要稿件条件时仍为草稿。

## 任务

- 任务ID、镜号、稿件版本：
- 模型、版本、模式、入口：
- 已读取的官方规范与对应模板：
- 实际参考文件及引用对照：
- 入口参数及当前校验报告：
- 稿件状态：草稿 / 正式稿（对应`formal_prompt_ready`）。
- 生成条件：具备 / 尚缺（对应`generation_ready`）；尚缺项及影响：
- 最终交付文件与内部`review.delivery`、校验报告位置：

### 镜头说明

第 X 段｜对应原分镜：镜头 XX—XX｜总时长：X 秒

| 镜头 | 时间（估算） | 景别与运镜 | 画面、表演和台词 |
|---|---|---|---|
| 1 | 0—X 秒 | | |
| 2 | X—X 秒 | | |

每段交付使用上述四列顺序。每行末列独立写清本镜光源、固定色温（K）和人物具体受光，并与对应模型镜头正文一致；不以表前公共说明或仅首行写光线代替其余行。按实际镜数增减行，单镜只保留一行；时间、景别、运镜和动作与本段提示词及有效分镜一致。“景别与运镜”合并写明景别和摄影机运动，并在需要时简明交代机位与拍摄角度；“画面、表演和台词”先按“画面位置 → 朝向 → 姿态 → 与他人、道具的关系”交代人物站位，再按时间顺序写清动作、反应、表演语气、光源与固定色温（K）、各可见人物的受光部位方向及必要的非对白声音，并把对白或旁白放在相应表演处，注明说话人和声音性质；无对白时自然描述画面，跨镜声音承接时注明。时间未实测使用“时间（估算）”，实测后按实际依据标注。保留原分镜镜号与本段切镜序号的对应关系。

**参考资产：**列出本段选用的人物、场景、道具和声音参考，以及各自职责；未确认或未提供的说明状态。纯文生且确无参考时也须明确写“无参考”及依据。

### 完整提示词

此处放置对应模型模板填写完成后的单独代码块。格式按模型规范，不能将本模板标题、说明或内部校验字段一并复制给视频模型。

**待验证事项：**只写实际存在的未验证事项及影响，例如压缩时长的容量风险；没有则写“无”。

### 稿件关联

- 对应分镜与素材版本：
- 同场同时跨视角光色核对：有效场景基准及版本、实际对照镜号或相邻段依据、光源空间位置／色温／灯光状态／明暗关系／整体色调结论；引用现有内部证据，不重抄全量记录。
- 同场相邻段景别衔接：上一段尾帧依据及景别／本段首帧景别／人物位置和动作承接；引用`dependency_files`与`continuity_context`，视频注明所查帧秒数；不适用时说明具体依据。
- 内部任务、输入指纹所在报告、检查时间及两项检查结论：
- 独立复检所见交付版本与报告位置、交付四列表格／模型格式／分镜资产内容的结论及内部证据引用：
- 画面文字转交索引位置与本段`post_note` ID；无转交项时说明：
- 尚缺条件及影响：

### 分镜与资产逐镜核对摘要

- 实际审读镜号与有效来源范围：
- 内部逐镜证据位置（`source_bindings`、`detail_checks`、`coverage`、`lighting`、`reference_requirements`及`judgments`）：
- 完整性与一致性结论、已处理问题及尚缺项：

逐项证据在内部任务维护一次，此处引用并呈现审读范围与结论，不手工重抄全量证据；不存在或未提供的资产如实标明。引用不能替代上方四列镜头表或参考说明，也不能替代实际审读。

内容或输入发生变化时重建完整稿并重新检查；仅改分辨率等参数的任务保留已确认正文，更新相关参数与检查绑定。
