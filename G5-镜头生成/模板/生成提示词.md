# 生成提示词

每个任务独立成节。提示词复制区只保留当前完整稿，旧稿归档；解释、版本差异及检查结果在复制区外维护。

## 任务

- 任务ID、镜号、稿件版本：
- 模型、版本、模式、入口：
- 已读取的官方规范与对应模板：
- 实际参考文件及引用对照：
- 入口参数及当前校验报告：
- 交付状态：草稿 / 正式可提交稿。

### 镜头说明

第 X 段｜对应原分镜：镜头 XX—XX｜总时长：X 秒

| 镜头 | 时间 | 景别 | 运镜 | 画面与声音 | 台词 |
|---|---|---|---|---|---|
| 1 | 0—X 秒 | | | | |
| 2 | X—X 秒 | | | | |

按实际镜数增减行，单镜只保留一行；时间、景别、运镜和动作与本段提示词及有效分镜一致。画面与声音写清人物位置、动作、反应及必要的非对白声音；台词栏写对应对白或旁白并注明说话人和声音性质，无台词写“无”，跨镜承接时注明。时间为估算时注明。保留原分镜镜号与本段切镜序号的对应关系。

**参考资产：**列出本段选用的人物、场景、道具和声音参考，以及各自职责；未确认或未提供的说明状态。

### 完整提示词

此处放置对应模型模板填写完成后的单独代码块。格式按模型规范，不能将本模板标题、说明或内部校验字段一并复制给视频模型。

**待验证事项：**只写实际存在的未验证事项及影响，例如压缩时长的容量风险；没有则写“无”。

### 稿件关联

- 对应分镜与素材版本：
- 同场相邻段景别衔接：上一段尾帧依据及景别／本段首帧景别／人物位置和动作承接；不适用时说明。
- 输入指纹、检查时间及两项检查结论：
- 尚缺条件及影响：

### 分镜与资产逐镜核对

| 镜号 | 已确认分镜要求 | 本镜实际选用资产、版本与参考职责 | 提示词对应内容与核对结果 |
|---|---|---|---|

记录实际依据与覆盖；不存在或未提供的资产如实标明。核对表不放入提示词复制区。

内容或输入发生变化时重建完整稿并重新检查；仅改分辨率等参数的任务保留已确认正文，更新相关参数与检查绑定。
