# 即梦 / Seedance 2.0写作骨架

先读取[2.0官方依据及规则](../模型提示词规范.md#即梦--seedance-20)。本骨架按官方自然语言公式与分镜顺序整理，花括号全部替换；它不是模型要求的固定API字段。

```text
{有参考时：按上传顺序定义素材中的主体与职责。纯文生时从主体、地点与事件开始。}
{原样写入本项目已确认画风与适用场景描述，再交代主体与事件。}

镜头1：{景别、机位与构图；明确主体位置和起始状态；按先后写动作轨迹、回应、摄影机过程与落点；该镜光源及空间来源、固定色温（K）、各可见人物受光部位方向与声音。}
{多镜继续镜头2、镜头3；单镜不补无关镜头。}

{贯穿的必要声音和画面要求。已在镜内交代的内容不重复。}
画面无任何文字，无背景音乐。
```

具体参考、视频编辑和延长须使用官方对应任务句式。即梦引用以实际上传后可见编号为准；声音符号沿用官方约定。按镜序写清动作先后，画幅与总时长在实际入口参数中同步设置。

固定描述的建立、确认与版本引用按[固定描述规范](../../固定描述规范.md)执行，具体措辞只在本项目维护。
