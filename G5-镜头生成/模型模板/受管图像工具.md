# 受管图像工具的输入与证据

单张快速概念图、定妆和局部首尾帧走 `image_gen.imagegen`。可对照[Codex 图像接口记录](../../G4-角色场景道具与声音资产/模板/image_gen.imagegen.schema.json)，有差异时在项目工作区保存本次声明。

角色三视图或四视图身份板、场景多角度、首尾帧成组制作及多参考批量出图，读取 `~/.codex/skills/infinite-canvas-operations/SKILL.md`。使用已配置的 Infinite Canvas MCP（`mcp__infinite_canvas`）或该技能的本机 Canvas Agent 接口。先读目标画布与实时 `workflowCatalog`，核对图像工作流、参考节点、槽位顺序和参数，回读连线与输入后按授权提交，跟踪原任务并检查返回原图。画布远端素材以 media_id 与可访问依据登记。实际图像由 Codex 原生看图检查；工作流或提示词的文字审读单独记录。

适用条件：本次环境提供真实图像工具及直接可读的接口声明。记录实际接口，不预设供应商或底层模型版本。本文件是工作记录规范，不是模型API的新字段。

1. 保存工具全名、模式、入口、当次声明的可读记录及SHA256。任务`model.spec_source.kind`使用`managed_tool_schema`，记录`tool_name`、`path`、`sha256`、`evidence`。外部官方资料继续使用原分支。
2. 未公开底层版本时，`model.version`留空，`version_status`为`not_exposed`，`version_unavailable_reason`具体说明。公开可选择版本的工具仍须记录并核实版本。
3. 按声明中实际支持的字段组织调用。当前环境若提供`image_gen.imagegen`，新图只使用实际存在的`prompt`与`transparent_background`等字段；新图省略编辑参考参数。编辑时的参考参数二选一及透明背景规则以当次实际声明为准，不能从本文件假定未来接口不变。
4. 目标画幅写`requested_aspect_ratio`（兼容任务的`aspect_ratio`目标字段）。没有实际尺寸参数时不添加参数；生成后记录真实像素/比例，不能以请求目标充当实测。
5. 图片任务完成格式与内容检查、必要的独立审读、当前指纹及授权检查后才提交。保留实际发送的完整输入、生成结果与看图记录；审美候选不自动成为用户选用。

程序只能检查声明记录与摘要、字段及输入绑定，不能证明声明来源真实、工具执行遵循提示词或图像质量达标。
