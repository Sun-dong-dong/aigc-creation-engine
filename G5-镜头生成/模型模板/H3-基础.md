# H3基础模式模板

使用前读取[模型规范H3条目](../模型提示词规范.md#h3)及其官方基础指南，确定T2VA、I2VA、FL2VA或L2VA。骨架中的花括号是待填内容，不进入最终稿。

T2VA直接填写下列三字段。I2VA、FL2VA、L2VA先写对应官方指令，空一行再接三字段。

```text
integrated_multimodal_description: [Shot 1] {Exact confirmed project style and applicable scene text; framing, angle, subject placement, exact light source and fixed color temperature in K, light falling on each visible character, action sequence, camera path and sound events.} No on-screen text. No subtitles. No background music.

overall_soundscape: {Ambient, physical and nonverbal sounds; N/A only for complete silence.}

non_diegetic_music: N/A
```

I2VA指令原句：

```text
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
```

FL2VA指令（替换N与S.SS，时间保留两位小数）：

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
```

L2VA指令（替换N与S.SS）：

```text
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

多镜时在描述中继续`[Shot 2] At MM:SS.mmm, ...`。说话人使用`(S1)`等编号，台词采用`<d>[Chinese] 原文</d>`等官方标记；旁白、跨镜及截断规则从官方指南按需读取。只保留本模式所需结构，主体内容按本次分镜完整填入。

固定描述的建立、确认与版本引用按[固定描述规范](../../固定描述规范.md)执行，具体措辞只在本项目维护。
