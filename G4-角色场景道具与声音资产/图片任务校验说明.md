# 图片任务检查

G3故事板或G4资产调用模型生成图片前，为本次图片准备[内部任务记录](模板/图片任务校验.json)及完整提示词文件。记录只用于内部检查；提交给图片模型的提示词使用该模型与模式对应的官方格式，受管工具调用则遵循本次实际公开的工具接口。用户满意素材直接接入、文字需求提取与手绘简图不创建生成任务。

按实际用途填写`kind`：`character_face`人物定脸、`character_outfit`人物全身造型、`character_views`人物四视图、`scene_overhead`场景俯视基础图、`scene_view`场景派生视角、`prop`道具、`storyboard`故事板，其余确属其他独立图片任务使用`other`。记录实际资产标识与请求目标画幅`requested_aspect_ratio`；旧字段`aspect_ratio`兼容保留，两个字段同时填写时须一致。目标画幅不证明入口提供画幅参数，也不证明已生成对应比例；只有实际入口存在的参数才能发送，工具仅有文本提示时如实记录其控制限制。输出后在独立生成与验收记录保存真实像素、实际比例及任务ID/输入指纹，不将输出元数据回写输入任务而使已核对输入的指纹无故变化；实际尺寸与内容验收不由本门禁自动判定。不能借更换类型绕过适用的确认节点。场景首图、定脸首图和独立道具不要求已有前置图片。

`model`记录实际模型或工具名称、模式、入口与规范依据，按实际入口二选一：

- **模型官方文档**：`spec_source.kind: official_document`（旧任务未写该字段时仍按此分支），继续填写真实`version`、`official_url`的HTTPS来源与`official_evidence`实际读取依据，不用未公开版本标记绕过这一分支。
- **受管工具声明**：确实通过本次运行环境提供的受管工具时，填写`spec_source.kind: managed_tool_schema`、实际`tool_name`、本地接口记录`path`与`sha256`、直接核对当前工具声明的`evidence`。接口记录为JSON，至少有匹配的`tool`、实际来源`provenance`与非空`input`字段声明；文件实际内容纳入输入指纹。此分支不要求为工具接口虚填外部网页。底层模型版本不公开时，`version`留空，写`version_status: not_exposed`及具体`version_unavailable_reason`；已公开版本照实登记，不能一边标未公开一边填猜测值。

受管工具名、接口记录及摘要只提供可追溯依据，程序无法证明该文件确实来自当前运行环境，也不能发现记录删掉的实际字段或限制。执行者须实际核对当前工具声明、允许字段与提交方式，记录核对范围；不能为通过门禁自造schema、任填工具名或拿其他API文档代替本次接口。模板中的规范分支须按任务选择，不能利用分支规避实际模型规范。

`prompt_file`指向本次完整提示词文本。`references`按实际输入登记资产标识、职责`roles`、本次指定或选用及依据；本地文件填写`path`与SHA256，已提供的非本地图片填写`media_id`及实际访问依据`access_evidence`。有多个职责时可由同一素材承担；用户选定和实际可用分别核对。

人物造型需要同一资产的已确认定脸参考（职责`identity`）；四视图需要已确认定脸与造型参考（`identity`、`outfit`）；场景派生视角需要已选定的同一场景俯视基准（`scene_base`）。人物新建定脸、造型、四视图分别按3:4、9:16、16:9记录。用户本轮明确指定例外时，`override.rules`只填写受影响的`ratio`、`character_sequence`或`scene_base`，并在`user_instruction`记录用户明确指令及适用范围；没有此类指令不填写例外。

完成真实的官方格式或受管工具接口检查，以及当前内容检查，在`review.format`、`review.content`分别记录结果与依据，生成当前输入指纹并写入`review.fingerprint`：

```sh
python3 "技能目录/G4-角色场景道具与声音资产/scripts/check_image_task.py" "项目内部检查/图片任务.json" --fingerprint
```

重新保存记录后运行：

```sh
python3 "技能目录/G4-角色场景道具与声音资产/scripts/check_image_task.py" "项目内部检查/图片任务.json" --report "项目内部检查/图片检查结果.json"
```

`--report`须使用独立输出文件；不能指向任务记录、检查脚本、完整提示词、规范接口记录或任一登记的本地参考素材，包括相对路径、软链接和已有硬链接别名。与`--fingerprint`同时使用也会先拒绝这些冲突；安全路径下仍只输出指纹，不写报告。

程序检查任务类型、请求目标画幅、已选择的规范依据分支、提示词/接口记录/参考文件摘要、当前步骤前置记录、格式和内容检查绑定。`formal_prompt_ready`表示这些输入记录通过；`generation_ready`还要求本次生成授权及范围。只有`generation_ready: true`可提交生成。仅有退出码0不代表已获生成授权。

输入、参考、模型或工具接口、任务步骤或用户指定例外变化后重新检查；单独补录本次生成授权不改变提示词内容检查的指纹。程序核对记录与版本，用户确认依据、官方资料或工具声明实际内容、非本地素材可访问性、分镜与资产语义及图像效果均须实际核查。生成后实际查看图像并核验真实尺寸，分别记录内容、制作适配、审美判断与用户选用。
