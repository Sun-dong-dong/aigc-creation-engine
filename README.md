# Aigc创作引擎

面向短剧、漫剧与剧情短片的 Codex 技能，覆盖创意、剧本、导演、分镜、美术资产、镜头生成、声音制作和剪辑后期。

支持从零开始共创，也支持承接已有剧本、分镜和素材，只完成当前需要的工作。可以逐项讨论、确认后执行，也可以在明确授权的范围内连续推进。

## G0—G7 工作流程

| 阶段 | 主要工作 | 说明 |
| --- | --- | --- |
| G0 创意与立项 | 选题、参考研究、核心创意、定位与制作条件 | [进入 G0](G0-创意与立项/阶段说明.md) |
| G1 故事与剧本 | 故事、人物、梗概、分集分场、剧本正文与审改 | [进入 G1](G1-故事与剧本/阶段说明.md) |
| G2 导演与视听设计 | 导演意图、视听风格、调度、镜头策略与声音叙事 | [进入 G2](G2-导演与视听设计/阶段说明.md) |
| G3 分镜设计 | 逐镜拍法、运镜、时长、衔接、故事板与预演 | [进入 G3](G3-分镜设计/阶段说明.md) |
| G4 资产 | 需求提取、用户素材接入、角色场景道具与声音资产、美术审美检查 | [进入 G4](G4-角色场景道具与声音资产/阶段说明.md) |
| G5 镜头生成 | 模型提示词、生成执行、镜头验收、修订与补镜 | [进入 G5](G5-镜头生成/阶段说明.md) |
| G6 声音制作 | 人声、音效、音乐、声画同步与混音 | [进入 G6](G6-声音制作/阶段说明.md) |
| G7 剪辑与后期 | 剪辑、节奏、调色、字幕、复核与交付 | [进入 G7](G7-剪辑与后期/阶段说明.md) |

按任务选择起点。例如，已有分镜只提资产需求时直接进入 G4，已有视频只改字幕时直接进入 G7。各阶段在制作过程中检查和调整，流程以 G7 为终点。

## 创作与制作方式

- **承接当前成果。** 沿用用户已确认的内容和有效版本，只补本次任务必需的信息。
- **按当前要求修订。** 先更新事实所属的有效来源，再同步受影响的方案、提示词和参考用途。正文变化交完整新稿；仅记录、引用或参数变化时保留正确正文，回查实际影响并更新检查绑定，不为版本号重复造稿；G5初稿处置仍按其校验说明执行。
- **重视阅读与视听表达。** 剧本使用清楚的场次、动作和对白格式；分镜写明景别、构图、运镜、表演和声音，镜头运动服务于叙事与情绪。
- **尊重用户美术选择。** 满意的人物、场景和道具图可直接接入；只提取需求时交资产清单，设计与生成按本次范围执行。
- **每条原样复用项目画风。** G2确定、G4落实本项目的固定画风和场景描述；G5每次读取当前确认版本，完整原样写入对应模型格式。程序检查遗漏、改写和版本，独立复检核对适用范围与冲突。具体方法见[固定描述规范](固定描述规范.md)。
- **按模型规范写提示词。** 外部模型读取匹配版本、模式与入口的官方依据；受管图像工具可记录当次实际接口声明，未公开底层版本如实披露。分别检查格式和内容；视频初稿的修订与无变动接纳按[G5校验说明](G5-镜头生成/校验说明.md)，不为制造版本号复制相同正文。
- **先规划生成分段。** 视频提示词写作前逐对判断相邻分镜的合并或拆分，连续表演与需单独控制的镜头按实际情况安排，并检查镜号、依据与时长。
- **绑定最终交付与检查依赖。** 四列表格、参考说明和唯一提示词复制区共同组成当前交付文件；前段尾帧等检查依赖单独登记，变化后旧复核失效。正式稿状态与可提交生成的条件分别说明。
- **依据实际结果交付。** 文字完成、文件生成、技术检查、实际看图试听和用户选用分别记录。
- **按稳定范围审读。** 已稳定的场或段可先审，正式交接按最终接收版本整理；视频提示词仍须审完整拟交付稿。复用有效检查，只回查变更及其实际影响，不因补全记录重开全片。
- **完成后明确下一步。** 每次任务完成或成果确认后，说明当前成果、下一步具体工作与预期交付、必要条件和推进方式；沿用已有授权与本次目标安排后续。
- **交接前核对实际成果。** 分镜进入资产准备时，必须交付分镜定稿、资产需求及复核交接记录，完成文件检查和逐镜内容复核；已有有效或合并文档可直接引用。

## 安装到 Codex

将整个仓库作为一个技能目录保存，保留 `SKILL.md` 与 G0—G7 的相对位置。

| 使用范围 | 技能目录 |
| --- | --- |
| 个人使用 | `~/.agents/skills/aigc-creation-engine/` |
| 当前项目使用 | `<项目目录>/.agents/skills/aigc-creation-engine/` |

目录约定见 [Codex 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

使用 GitHub CLI 安装到个人目录的示例（macOS / Linux）：

```sh
gh auth login
mkdir -p "$HOME/.agents/skills"
gh repo clone Sun-dong-dong/aigc-creation-engine "$HOME/.agents/skills/aigc-creation-engine"
```

仓库为公开仓库，可直接克隆。已有同名安装时，先核对现用目录与版本，再进行更新。

## 调用与使用示例

在 Codex 中输入 `$aigc-creation-engine`，再说明本次任务。提供现用文件或准确路径，并说明交付范围、沟通方式及是否可以写入或生成。

### 从创意开始

```text
$aigc-creation-engine
我想共创一部短剧，先从核心创意开始。每次只讨论一个问题，等我确认后再执行。
```

### 承接已有剧本

```text
$aigc-creation-engine
读取我提供的剧本，只检查这场戏的人物动机、动作因果和对白。先给审稿意见，不改正文。
```

### 只提取资产需求

```text
$aigc-creation-engine
只提取这份分镜所需的角色、场景和道具资产，列出用途、镜号和必要状态。满意素材由我提供，本轮不设计或生成。
```

### 准备视频提示词

```text
$aigc-creation-engine
按我指定的模型、版本和入口，为这组确认分镜准备提示词。先读取对应官方规范与模板，完成格式和内容检查，本轮不调用模型生成视频。
```

## 材料与工具

创意和文字工作可按现有信息开展；涉及已有作品时，提供本次使用的准确版本与已确认要求。缺失内容按任务需要补充。

实际图片、视频、配音、音乐或后期制作，需要相应的可用工具、模型入口及素材访问权限；生成和导出按用户授权范围执行。作品、素材和制作记录保存到指定项目目录。

共同[模型提示词规范](G5-镜头生成/模型提示词规范.md)收录模型依据与适用范围，包括 H3 基础与全参考、即梦 / Seedance 2.0、2.5、VoxCPM2 人声及受管图像工具的实际接口记录。使用时核对匹配依据和实际入口；未覆盖的模型先建立匹配规范，不虚填版本或挪用其他入口资料。

G3 交接检查与 G5 视频任务校验脚本均使用 Python 3 标准库，运行方法见[G3阶段说明](G3-分镜设计/阶段说明.md#制作交接门禁)和[G5校验说明](G5-镜头生成/校验说明.md)。脚本检查文件或任务输入，不调用生成模型。图像和声音任务使用各自规范。

技能执行入口与完整路由见 [SKILL.md](SKILL.md)。
