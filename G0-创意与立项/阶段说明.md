# G0｜创意与立项

将创作意图和已有材料发展为清晰的作品方向，形成供故事开发使用的《立项方案》。

## 一、进入方式

根据已有成果确定起点：

- **没有明确想法**：从感兴趣的内容、具体感受或参考材料中寻找创意。
- **已有脑洞**：围绕核心情境开发，检验它能产生怎样的行动和变化。
- **已有原作**：核对材料范围、改编目标和允许调整的边界。
- **已有大纲或剧本**：提取现有定位和规格，补齐立项缺口，保留已确认内容。

## 二、六项工作

| 子项 | 执行内容 | 形成结果 |
|---|---|---|
| **G0.1 输入与来源整理** | 阅读指定材料，识别本次创作范围；区分来源事实、用户要求和创作提案 | 材料来源、已确认要求、当前缺口 |
| **G0.2 参考与选题研究** | 围绕具体创作问题查看参考，分析吸引点、实现方法及适用条件；商业项目按需研究市场 | 有证据的观察、可借鉴方法、使用边界 |
| **G0.3 核心创意开发** | 提炼人物处境、行动目标、主要阻力和预期变化；检验创意如何进入事件，系列作品检查持续展开能力 | 一句话创意、核心看点、差异化依据 |
| **G0.4 作品定位** | 明确作品类型、时代背景、主要观看对象及希望带来的感受；确定必须保留的特点和创作取舍 | 作品定位、观众期待、核心创作要求 |
| **G0.5 体量与基本规格** | 结合内容和用途确定单片或系列、时长、集数、画幅、交付形式及主视频模型和实际生成入口 | 已确定规格、建议范围及其依据 |
| **G0.6 制作条件初评** | 核对资源、预算、工期和关键效果；识别可能影响创意成立的制作难点 | 可用条件、关键风险、验证需求 |

## 三、执行规则

按[精品档位与质控指南](../精品档位与质控指南.md)确定「制作档位」，可选精品短剧、精品漫剧、电影感短片。在立项方案与锁定卡记下选择依据。方向未定时给 1–2 个与当前材料匹配的选项，等用户确认后再锁定。

- 从材料与已有对话提取答案，先提出基于实际材料、已确认要求和本次目标的具体候选与理由；区分原作事实、用户确认、AI建议和待定事项。只询问无法合理判断且影响核心方向或执行的缺口，不把助手建议或未答复当成确认。
- 按用户沟通方式推进：逐步共创时围绕当前问题讨论；用户要求完整方案或授权自主决定时，在授权范围内作必要判断并给出可审阅方案。可集中确认相互关联的核心问题，不把每个字段变成一次追问。用户明确要求的确认节点继续保留。
- 参考研究标明实际查看范围。观察、解释和未知内容分别记录；借鉴须转化为本作品自己的处境与行动。
- 检验核心看点时，从本作品选一个能拍出来的关键情境，写清人物要做什么、遇到什么阻力、什么可见变化让观众想往下看。检查创意差异时，比较人物关系、行动策略和关键变化。
- 未定名角色先用身份或关系称呼；已有确认名字沿用。正式命名时核对获准使用的已用名记录。
- 已指定的规格按要求执行。为视频制作立项时，确定主视频模型及实际生成入口，在立项方案和锁定卡「视频模型与入口」登记模型、入口与全参考模式。首选范围为 H3 Ref2VA、即梦 2.0 全能参考、即梦 2.5 全能参考。沿用用户已选的方案；缺选择时在立项集中确认，用户授权自主决定时按制作条件选择并记录依据。仅创意、剧本等暂不涉及视频制作的任务可保留待定。旧项目沿用实际记录，缺项先确认；未确定时可继续与模型无关的工作，依赖具体入口的分段和素材规格保持待定。
- 关键效果分别记录已验证、待验证或已知不适配的依据。需要试样时明确验证内容、通过标准和投入上限。
- 用户明确接受后，提案才进入已确认内容。方向变更时更新现行方案，并指出受影响部分。

## 四、产出与完成标准

每部作品在自己的项目目录中建立 `G0-创意与立项/`，保存：

- **立项方案.md**：集中承载六项工作结果，标明已确认内容与待定事项。使用[立项方案模板](模板/立项方案.md)，根据实际工作逐项填写。
- **项目规格与锁定卡.md** 使用[锁定卡模板](模板/项目规格与锁定卡.md)汇总当前要求、制作档位、版本和待定事项。状态可填“已确认／自主决定／建议／待定”，依据注明原件与授权范围。旧项目已有纯 Markdown 卡时原地补缺，保留历史依据。
- **参考研究.md**：开展参考研究时建立，保留观察、分析、出处和查看范围。使用[参考研究模板](模板/参考研究.md)。
- **参考资料/**：存放本项目获准保存的原始材料。

“画面比例”按确认范围登记。仅确认横竖屏时注明具体比例待定。“时长与集数”的暂估值标为建议，硬时限按用户已确认的范围登记。

进入 G1 前，应能清楚回答：

1. 这部作品讲什么，最值得看的地方是什么？
2. 希望观众获得怎样的体验？
3. 准备采用什么体量和基本规格？走视频制作时，主视频模型和实际全参考入口是否已明确？
4. 哪些要求必须保留，哪些问题尚需解决？
5. 是否存在会推翻创作前提的未决问题？

核心方向经用户确认且影响创作前提的问题已处理后进入 G1。方向未定时先给 1–2 个选项等待确认。用户授权自主处理的执行细节另记范围与依据。G1 负责完整人物、世界规则、大纲和剧本；G2 负责具体导演与视听设计。
