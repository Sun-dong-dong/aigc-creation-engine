# 复核与交接

## 本次交付与检查依据

- 任务范围与约定完成标准：
- 当前工程/剪辑、装配信息及对应版本：
- 实际交付文件、版本与位置：
- 已定叙事、导演、美术、声音与文字依据：

|---|---|---|---|---|---|
| | | | | | |

连续看听、局部回放、抽帧、技术测量与文本识别分别说明。无法实际观看或试听时保留待检；程序通过或单帧满意不能替代成片验收。

| | | | | | |

## 输出规格与工程对应

- 工程或可复现装配信息、依赖及实际文件形态：
- 导出文件、对应剪辑版本与执行记录：
- 实测时长、尺寸/画幅、帧率、编码及音频规格：
- 可解码/完整播放的实际检查方式与覆盖范围：
- 约定规格差异与处理；未导出时的实际交付范围：

渲染文件与可编辑工程分别登记。只有混合音轨或烧录文字时如实说明，未取得的工程和独立声部不记为已交付。

## 本次交付

- 本次制作完成部分及实际证据：
- 待审准确版本、范围及审片文件位置：
- 素材引用、装配对应、声音与字幕及处理记录索引：
- 有转交项时，G5画面文字转交索引与稳定ID逐项接收、事件映射、制作及入画检查记录；无转交项时的核对范围与依据：
- 尚未接收／制作／回看或待确认的文字ID、影响及处理安排；全部落实时的具体依据：
- 已知问题、临时素材、待看听/待修/待确认项：
- 后续变化需回查的内容：
- 当前完成状态与用户确认依据：

候选可以按候选状态交付。局部完成、技术检查、实际看听与用户选用分别判断，交付审片文件不代表用户已确认定稿。
