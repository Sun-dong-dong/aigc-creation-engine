# 字幕与画面文字

## 内容与时间依据

- 本次任务：文字方案/可编辑字幕文件/入画制作及具体范围：
- 已确认文本、实际声音及准确版本：
- 当前剪辑/工程版本与时间基准：
- 已有可编辑字幕、烧录文字、样式及直接保留部分：
- 文本与声音差异、确认处理依据：
- 文字事件采用的时间单位；按帧时的帧率：

## G5画面文字逐项接收

- G5 `post_handoff_file`指向的实际转交索引、版本及绑定记录位置：
- 实际核对范围；无转交项时的核对依据：

| G5 post_note ID（原样） | 镜号及source_quote原文位置 | 接收状态（已接收／未接收／待确认） | 本阶段文字事件ID | 制作状态及实际文件 | 入画回看结果与证据位置 | 缺口／变更确认依据 |
|---|---|---|---|---|---|---|
| | | | | | | |

逐项对照G5索引的稳定ID、镜号和分镜原文，不将视频无字要求当成取消文字。同一ID在多处内部证据出现时对应同一文字事件；原索引已有原文，此处引用其准确位置，无须重新手工抄录。已接收不等于已制作，已制作不等于入画检查通过。取消或修改须有有效确认依据，遗漏、待制作、待确认项持续列明；不回写已绑定的G5索引以更新接收状态。

## 文字事件

| 事件ID | 类型 | 确认文本 | 说话人或来源 | 镜号/装配条目 | 成片入点 | 成片出点 | 断句/换行 | 样式引用 | 避让或揭示要求 | 状态 |
|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | |

类型按实际内容区分对白、旁白、片名、时间地点、场景内文字等，不为补齐类别增写内容。原文差异先核对，不由识别结果擅自改词；显示时机保留已定揭示顺序。

## 排版与场景文字

- 当前样式版本、字体与实际可用字体文件：
- 字号、颜色、位置、对比与画幅：
- 表情、动作、证据及观看界面的避让范围：
- 场景文字的透视、跟随运动与前后遮挡：
- 动效或强调的用途；已有烧录文字的处理与避免重复方式：

## 实际产物与校对

- 可编辑文本/字幕/图层文件、版本及位置：
- 实际入画文件与对应剪辑版本；未制作时说明：
- 字词、人名数字、断句与时间核对记录：
- 实际画面中的阅读、缺字、遮挡与重复检查范围及结果：
- 修订回看、用户选用与待检记录位置：
- G5转交ID逐项落实与未决项的最终核对位置：

只交文字文件不记为已烧录或已完成画面检查。剪辑变化后回查受影响事件，字体缺字和样式未实际渲染的部分保留待检。
